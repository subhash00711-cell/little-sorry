Your link is created on this device. To share it with anyone, first publish this single HTML file free using GitHub Pages (steps below).

  1. Download this HTML file.
  2. Sign in or create a free account at GitHub.
  3. Create a public repository named little-sorry.
  4. Upload this file and rename it index.html.
  5. Open Settings → Pages → choose Deploy from a branch → main → /(root) → Save.
  6. GitHub gives you a public website URL. Open it, personalise the page, and copy the gift link.
